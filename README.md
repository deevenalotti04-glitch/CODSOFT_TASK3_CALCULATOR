# 🚀 Luxury Futuristic Calculator

A modern, responsive calculator built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. The project features a premium futuristic dark theme with glassmorphism, neon blue and purple accents, smooth animations, and full keyboard support.

## ✨ Features

* Responsive design for desktop and mobile
* Futuristic dark UI
* Glassmorphism calculator card
* Neon blue & purple glow effects
* CSS Grid button layout
* Rounded corners and smooth transitions
* Hover and click animations
* Basic arithmetic operations

  * Addition (+)
  * Subtraction (−)
  * Multiplication (×)
  * Division (÷)
* Percentage (%)
* Decimal support
* AC (Clear) button
* DEL (Delete last character)
* Equals (=)
* Keyboard input support
* Error handling for invalid expressions
* Calculation history display

## 🛠️ Technologies Used

* Vanilla JavaScript

## ⌨️ Keyboard Shortcuts

| Key       | Action                |
| --------- | --------------------- |
| 0–9       | Enter numbers         |
| +         | Addition              |
| -         | Subtraction           |
| *         | Multiplication        |
| /         | Division              |
| %         | Percentage            |
| .         | Decimal               |
| Enter     | Calculate result      |
| Backspace | Delete last character |
| Esc       | Clear calculator      |

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional software or libraries are required.
